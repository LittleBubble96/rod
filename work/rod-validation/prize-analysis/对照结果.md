# 差异化计分敏感性实验

使用当前正式 JSON 的200个电脑布局；每关每表100局，四表共80000局。相同起始种子、两次免费重投，无广告/复活/付费，不应用教学首投。布局原按统一10/5筛选，有选择偏差。

策略：最大化当前玩家分减最高电脑分，其次玩家分、组枚数、面序。没有改善且仍有免费次数则重投。使用生产 RodRules.Score/NextFace。

争夺代理指标：夺首率=落子后在该区升为第一且挤掉原电脑第一的动作比例；同值抵消率=落子后自身与任意电脑同正筹力的动作比例。仅描述本策略行为，不代表真人竞争强度。接近结局=玩家分与最高电脑分差绝对值≤3。
