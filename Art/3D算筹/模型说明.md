# 3D 算筹基础模型 · 2026-10-16

文件目录：`TEngine/UnityProject/Assets/AssetRaw/Models/RodDice`。

- `RodDice.prefab`：直接拖入 Unity 场景。只有 MeshFilter 和 MeshRenderer，不含物理、碰撞或运行时网格生成脚本。
- `RodDiceMesh.asset`：中心轴心，边长 1 Unity 单位，圆角半径 0.14；1014 顶点、1728 三角面。六面共享一个子网格和一个材质。
- `RodDiceIvory.mat`：内置渲染管线 Standard 材质，象牙色底、青绿色图案。引用共享的 512×768 纹理，开启 GPU Instancing；是否实际合批由场景、渲染配置决定，未做真机性能测试。
- `RodDice.obj`、`RodDice.mtl`、`RodDiceAlbedo.png`：供 Blender 等建模软件继续编辑，三个文件一起使用。OBJ 采用右手坐标，已转换 X 和三角形绕序。
- `RodDiceSpin.anim`：两秒循环原地翻转资源，不改变位置，不默认播放。可在 Animation 窗口预览或加入 Animator。它不负责选择结果面、减速停稳或业务结算。

Unity 模型局部面朝向：风 +Y、花 +Z、雪 +X、月 -Y、方 -Z、圆 -X。对面配对是本基础模型的美术排布，不改变已有随机和计分规则。图案使用项目已有的六张透明花色图，未改原 UI 切图。

这是可用的立体基础款，不是对扁平原稿材质的逐像素重建。当前没有筹力刻槽，也没有区分 1/2/3 筹力的三个外观版本；未将模型接入正式对局或替换原 UI。

编辑期制作入口：`Assets/Editor/Rod/RodDiceModelBuilder.cs`。仅在编辑器生成资源；重跑会覆盖本工具输出，请先保存手工调整。模型通过 Unity 2022.3.62f2 隔离工程导入和实际渲染，OBJ 焊接位置后检查表面封闭、所有边被两个三角形共享、无退化及反向三角形。

预览：`Art/3D算筹/RodDice-preview.png`。日志：`work/rod-validation/dice-model.log`。未修改主场景、计分、关卡或引擎版本。
